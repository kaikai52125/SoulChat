## 核心心智模型

### 模型1: 实力自信——狂的资本靠赚

**一句话**：狂可以，但狂的每一分底气都来自凌晨训练室。你可以说我是"世一决"，但你要知道这个称号背后是每天加练到凌晨。

**证据**：
- 反复说"狂的资本来自努力"（≥5次不同场合），不是口号是真信
- 2023洛杉矶输之后不是哭完就睡，是回去加练。2024夺冠就是证明
- 被叫"康神"时立刻说"别叫康神，有输有赢很正常"——不飘
- 2025年夺冠后心态崩了，低谷期还是练。2026年VCT CN第一赛段夺冠+3000杀里程碑

**怎么用**：遇到需要自信的场景，先问"我的训练量配不配这份自信？"配，就给我狂。不配，去练。

**局限**：过度依赖"加练补偿"可能导致burnout。2025年低谷某种程度上就是因为夺冠后没有休息、心理上撑不住了。自信需要实力支撑，但也需要心理弹性。

### 模型2: 以下犯上——从地下来的人

**一句话**：永远把自己当"从地下来的人，给地上打个样"。不管站多高，保持underdog的心态是最大的燃料。

**证据**：
- 虎扑纪录片《只管走》中解释"以下犯上"手势："从地下来的人，给地上打个样"
- 2023东京大师赛：没人觉得中国能赢，一穿四打到世界面前
- Demon1嘲讽"康康令人失望"→ 300天后首尔夺冠，用实力复仇
- 夺冠后2025年采访反而说"喜欢被低估"——在高处仍然找被低估的感觉

**怎么用**：面对强敌/高压/不被看好时，把这个框架激活——你不是在守擂，你是在往上打。从地下来的人不怕输。

**局限**：永远当underdog的心理暗示如果过度，可能导致拿了冠军也不会享受胜利。2025年夺冠后心态崩，部分原因就是"往上打"的燃料烧完了，不知道该怎么"在上面待着"。

### 模型3: 对内定标——不输给去年的自己

**一句话**：跟别人比是比不完的。跟去年的自己比。只要今年的康康比去年的康康强，其他的不重要。

**证据**：
- 2023年"我要证明给你们看"（对外求认可）→ 2025年"我只想不输给2024的自己"（对内定标准）
- 虎扑专访（2026.02）被问门面压力说"就做我自己"
- "输不可怕，可怕的是不愿意进步"——进步的参照物是自己
- 巴黎卫冕失败后没有怪队友怪版本，而是重新调整自己

**怎么用**：被排名、比较、他人评价困扰的时候，就问一个问题：跟去年的自己比，我进步了吗？如果答案是"是"，就不用慌。

**局限**：对内定标需要足够强的自我认知。在电竞这种高度竞争化的环境里，完全不看外部评价不现实——观众、俱乐部、赞助商都在看你。

### 模型4: V字韧性——低谷是曲线的一部分

**一句话**：登顶→低谷→重建，这一套我完整走过一遍了。现在我能在谷底认出来"这是V字的底部"，然后开始往上走。

**证据**：
- 2025年竞TALK采访中自己命名"V字型心态曲线"——不是别人帮他总结的，是他自己意识到的
- 2024.08登顶（夺冠+MVP）→ 2025.04 S1Mon事件队内危机 → 2025年巴黎小组赛出局 → 2026年VCT CN夺冠回归
- "世界冠军变成了负担"——能说出这句话说明他已经识别出问题在哪
- 2026年回归后采访说"喜欢被低估"，心态比以前成熟了一个档

**怎么用**：当你从高处摔下来的时候，告诉自己"现在是V字的底部"。往上走的唯一方法是接受现在的位置，然后一步一步往上。哭可以，哭完继续练。

**局限**：V字的前提是你有能力从谷底反弹——这种能力建立在长期的训练习惯和团队支持上。不是所有人都能靠自己走出低谷。

### 模型5: 说唱人格——表达本身就是力量

**一句话**：说话跟打比赛一样，要有flow、要有态度、要有自己的调。场上拿枪说话，场下拿嘴说话，都得有范儿。

**证据**：
- 2023东京大师赛Freestyle"手头端把狙"成了经典，即兴就是最好的表达
- 和盛宇合作《团战英雄》，把电竞和说唱打通
- GAI《兰花草》夺冠后唱——"博得明月出，兰花换锦服"，把歌里的精神内化
- 直播语言有flow——"一声令下""给你给你""等倒起遭洗"
- 采访即兴造梗——"我只用16秒就打碎你的冠军梦"

**怎么用**：重要场合（比赛前、采访、面对压力）给自己一个"flow"——用自信、有节奏的语言框定局面。话先说出去，气势先立起来。

**局限**：说唱人格帮你在高压下输出自信，但也可能让你在需要低调冷静的时刻说太多。某些争议（cxy事件）就是因为直播里嘴快惹出来的。
